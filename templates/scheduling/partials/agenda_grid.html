{% load i18n clinic_locale %}{% comment %} Multi-resource day grid (todo 23 slice, variant A). One column per practitioner, then one per room; rows are clinic-local half hours. Every appointment is a link to its own reschedule page, so the grid works with JavaScript off. static/js/agenda-grid.js adds drag-to-move and the M move dialog; static/js/components/resource-grid.js adds the roving tab stop. The data-* attributes carry only opaque ids, revisions and times. Swaps settle at 0 ms: HTMX installs the new grid's realtime trigger when it settles, so a hint landing inside a settle delay would otherwise be lost. The move outcome lives in #agenda-grid-announce, outside the refetched region, so the realtime echo of the user's own move cannot erase it. {% endcomment %}
